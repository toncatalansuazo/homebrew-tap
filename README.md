# toncatalansuazo/tap

Homebrew casks for [Glasspen Meet](https://github.com/toncatalansuazo/glass-meet-pen): draw on your
screen while you share it in a call, from the Mac or from an iPhone/iPad.

```bash
brew install --cask toncatalansuazo/tap/glasspen-meet
```

The app is not notarized by Apple yet. The first time you open it, go to
**System Settings → Privacy & Security** and click **Open Anyway**.

Update with `brew upgrade --cask glasspen-meet`; remove with `brew uninstall --cask glasspen-meet`
(`--zap` also removes its settings).
